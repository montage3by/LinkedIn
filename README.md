# LinkedIn

Claude Code skills for running a LinkedIn account, vendored from
[Jakeschincariol/linkedin-agent-skill](https://github.com/Jakeschincariol/linkedin-agent-skill) (MIT).

Skills live in `.claude/skills/` and load automatically in any Claude Code session opened on this repo:

| Command | What it does |
|---|---|
| `/li-post` | post from a raw idea, 21 hook formulas |
| `/li-comment` | comments on other people's posts |
| `/li-reply` | replies under your own posts |
| `/li-dm` | connection notes and DM follow-ups |
| `/li-inbox` | inbox and connection-request triage |
| `/li-profile` | profile score out of 100 + rewrites |
| `/li-plan` | weekly plan: what, when, who to engage |
| `/li-carousel` | carousel / document post |
| `/li-repurpose` | one long asset into a week of posts |
| `/li-audit` | what worked in past posts and why |
| `/li-human` | strip AI fingerprint, score the draft |

Voice: fill in `.claude/linkedin/voice.template.md` and save it as `~/.claude/linkedin/voice.md`.
